# Source Verification Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Re-verify every data source on the site, mark unverified sources as such in the UI, and ship an automated guardrail that catches future drift.

**Architecture:** Two phases. Phase 1 produces an audit document that grids every registered source against URL liveness, schema match, narrative-only repro docs, UI consumers, backend client, and proposed status. Phase 2 codifies findings as new frontmatter fields (`verification_status`, `verification_notes`), surfaces them in `SourceMarker` / `SourcePopover` / `/data` pages, and ships `verify-sources.mjs` (Node) + a weekly GitHub Action.

**Tech Stack:** Node 25 (frontend tooling), Vite + React 19 + TypeScript 5, gray-matter for frontmatter parsing, Node 25 built-in `node:test` runner.

### Task 2: Fill URL liveness column

**Files:**
- Modify: `docs/superpowers/audits/2026-06-06-source-verification.md`

- [ ] **Step 1: For each `kind: api` and `kind: csv` source, hit the documented upstream**

```bash
# Read upstream from each MD's frontmatter and call it with curl.
# Skip kind=seed and kind=synthesized.
for f in docs/data-sources/*.md; do
  id=$(basename "$f" .md)
  [[ "$id" == "_TEMPLATE" || "$id" == "INDEX" ]] && continue
  upstream=$(grep -E '^upstream:' "$f" | head -1 | sed -E 's/upstream:\s*//')
  kind=$(grep -E '^kind:' "$f" | head -1 | sed -E 's/kind:\s*//')
  echo "=== $id ($kind) ==="
  echo "  URL: $upstream"
  if [[ "$kind" == "api" || "$kind" == "csv" ]]; then
    curl -s -o /dev/null -w "  HTTP %{http_code}  content-type: %{content_type}  size: %{size_download}\n" \
      --max-time 15 -L "$upstream" || echo "  UNREACHABLE"
  fi
done
```

- [ ] **Step 2: Record each result in the table's "URL liveness" column**

Use the format `HTTP 200 (application/json)` for live sources, `n/a (seed)` / `n/a (synthesized)` for static ones, `HTTP 404 unreachable` for failures.

- [ ] **Step 3: For any SCB PxWeb endpoint that returns 404/405 on GET**, note that PxWeb tables are POST-only metadata endpoints; treat 405 on GET as "live" if the URL still resolves to the table metadata page.

```javascript
const REQUIRED_KINDS = ["api", "csv", "seed", "synthesized"];
const REQUIRED_STATUSES = ["verified", "frozen", "unsure"];

function validateStatus(file, fm) {
  if (!fm.verification_status) {
    throw new Error(`${file}: missing 'verification_status' (one of ${REQUIRED_STATUSES.join(", ")})`);
  }
  if (!REQUIRED_STATUSES.includes(fm.verification_status)) {
    throw new Error(
      `${file}: verification_status must be one of ${REQUIRED_STATUSES.join(", ")}, got "${fm.verification_status}"`
    );
  }
  if (fm.verification_status === "unsure") {
    const notes = (fm.verification_notes ?? "").toString().trim();
    if (!notes) {
      throw new Error(
        `${file}: verification_status=unsure requires non-empty 'verification_notes'`
      );
    }
  }
}
```

```javascript
// frontend/scripts/verify-sources.mjs
import { readdir, readFile, writeFile } from "node:fs/promises";
import path from "node:path";
import { fileURLToPath } from "node:url";
import matter from "gray-matter";

const __dirname = path.dirname(fileURLToPath(import.meta.url));
const REPO_ROOT = path.resolve(__dirname, "..", "..");
const SRC_DIR = path.join(REPO_ROOT, "docs", "data-sources");
const REPORT_PATH = path.join(REPO_ROOT, "frontend", "verify-report.json");
const TIMEOUT_MS = 10_000;

export async function checkSource(entry, { fetch: fetchImpl = globalThis.fetch } = {}) {
  if (entry.kind === "seed" || entry.kind === "synthesized") {
    return { id: entry.id, status: "skipped", reason: `kind=${entry.kind}` };
  }
  if (!entry.upstream) {
    return { id: entry.id, status: "skipped", reason: "no upstream URL" };
  }

  const controller = new AbortController();
  const timer = setTimeout(() => controller.abort(), TIMEOUT_MS);

  let res;
  try {
    res = await fetchImpl(entry.upstream, { method: "HEAD", signal: controller.signal });
    if (res.status === 405) {
      // Some endpoints don't support HEAD. Fall back to GET.
      res = await fetchImpl(entry.upstream, { method: "GET", signal: controller.signal });
    }
  } catch (err) {
    clearTimeout(timer);
    if (err.name === "AbortError") {
      return { id: entry.id, status: "timeout" };
    }
    return { id: entry.id, status: "error", reason: String(err.message ?? err) };
  }
  clearTimeout(timer);

  const contentType = (res.headers.get?.("content-type") ?? res.headers.get?.("Content-Type") ?? "").toString().toLowerCase();

  if (!(res.status >= 200 && res.status < 400)) {
    return { id: entry.id, status: "unreachable", httpCode: res.status };
  }

  if (entry.kind === "csv") {
    const okType =
      contentType.includes("csv") ||
      contentType.includes("zip") ||
      contentType.includes("octet-stream");
    if (!okType) {
      return {
        id: entry.id,
        status: "wrong-content-type",
        httpCode: res.status,
        contentType,
      };
    }
  }

  return { id: entry.id, status: "ok", httpCode: res.status, contentType };
}

async function loadEntries() {
  const files = (await readdir(SRC_DIR)).filter(
    (f) => f.endsWith(".md") && !f.startsWith("_") && f !== "INDEX.md"
  );
  const entries = [];
  for (const f of files) {
    const raw = await readFile(path.join(SRC_DIR, f), "utf8");
    const { data: fm } = matter(raw);
    entries.push({
      id: fm.id,
      kind: fm.kind,
      upstream: fm.upstream && fm.upstream !== "~" ? fm.upstream : null,
    });
  }
  return entries;
}

async function main() {
  const entries = await loadEntries();
  const results = await Promise.all(entries.map((e) => checkSource(e)));
  const failures = results.filter(
    (r) => r.status !== "ok" && r.status !== "skipped"
  );

  await writeFile(REPORT_PATH, JSON.stringify({ results }, null, 2));

  for (const r of results) {
    const line =
      r.status === "ok"
        ? `  ✓ ${r.id} — HTTP ${r.httpCode} (${r.contentType})`
        : r.status === "skipped"
        ? `  · ${r.id} — skipped (${r.reason})`
        : `  ✗ ${r.id} — ${r.status}${r.httpCode ? ` (HTTP ${r.httpCode})` : ""}${r.reason ? ` — ${r.reason}` : ""}`;
    console.log(line);
  }

  if (failures.length > 0) {
    console.error(`\nverify-sources: ${failures.length} source(s) failed verification`);
    process.exit(1);
  }
  console.log(`\nverify-sources: ${results.length} source(s) checked, all healthy`);
}

// Only run main() when invoked as a script, not when imported by tests.
if (import.meta.url === `file://${process.argv[1]}`) {
  main().catch((err) => {
    console.error("verify-sources failed:", err.message);
    process.exit(1);
  });
}
```
